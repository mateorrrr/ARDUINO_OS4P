# **Components and Materials**

The following list includes all competent you are handed in at the beginning this project. To build the Arduino CO2 sensor you will only need to use the one marked as yes. 

| Component | Image | Specifications and description | Was it used? |
|---|---|---|---|
| Breadboard | <img src="../Images/breadboard.jpg" width="150">| Allows temporary connections between the Arduino and the other components (sensors and SD card) | Yes |
| Arduino Uno | <img src="../Images/arduinoUNO.jpg" width="150"> |Central microcontroller of the system. It translates the Arduino IDE code to communicate to the sensor, process the measurements and collect the data. <br> <br>&bull; Model: ATmega38P <br>&bull; Operating voltage: 5V <br>&bull; Connection type: USB-C | Yes |
| Cables | <img src="../Images/cables.jpg" width="150"> | Connects the different components of the circuit  | Yes |
| CO2 Sensor | <img src="../Images/CO2sensor.jpg" width="150">| Measures the carbon dioxide concentration in its surroundings using infrared technology <br> <br>&bull; Model: HH-Z19C <br>&bull; Manufacturer: Winsen <br>&bull; Measurement range: 400-2000ppm | Yes |
|P/T/RH sensor| <img src="../Images/P-T-RHsensor.jpg" width="150">| Sensor module that allows to take extra environmental measurements such as pressure, temperature and relative humidity <br> <br>&bull; Model: BME/BMP2080 | No |
| SD card and SD reader | <img src="../Images/SDcard+addapter.jpg" width="150">| Collects and preserves experimental data for later analysis.  | Yes |
| External battery| <img src="../Images/powerbank.jpg" width="150">| External power supply that allows the Arduino to operate without a continuous connection to the computer. Useful to make long measurements. <br> <br>&bull; Manufacturer: VARTA <br>&bull; Maximum charging power: 20W <br>&bull; Outputs: 2 USB-C and 1 USB-A port | No |
| USB-C cable | <img src="../Images/USBcable.jpg" width="150">| Provides connection between the Arduino ONE and the computer or battery | Yes |
